The work

Noonmark

Noonmark is a task list for Android. You capture a thought in a few words and it asks for nothing else. A day is optional, and it is never a time. The main screen sorts what you have into Overdue, Today, Upcoming and Anytime, and says so in one quiet line when nothing requires you.

Tap a row to finish it. Swipe to delete, with five seconds to undo. A finished task leaves the list the day after. Backup saves everything to a plain JSON file where you choose, and Restore reads one back.

The name

The mark the sun makes on a meridian line at noon: a fixed mark read by daylight to know where you are.

The launcher mark is a brass diamond set on a horizontal day-line. The sentence above is from the decision log, 13 October 2026.

Refused

What Noonmark will not do.

  • No streaks. No badges.

    Overdue is stated in one muted tone. There are no failure counts, no sharing prompts and no cheering.

  • No account.

    There is no sign-in and no server. Your tasks live in a private database on the phone.

  • No network.

    The release build makes no network requests, and the app asks Android for no permissions.

  • No time of day.

    A task can have a day. It never has an hour.

  • No analytics. No ads.

    It collects no data. Not a little, not anonymous, not metadata.

  • No promise it cannot keep.

    Copy that claims what the build does not do is on the never list. Every line is checked against the code before it ships.

The underside

Finished like the front.

A coat is judged inside out, and its lining is finished like the front. These are the parts of Noonmark that nobody opens.

Tests

15 automated tests cover how tasks are sorted into days, how a backup file is checked, and the contrast of the accent text.

Contrast

Accent text reaches 4.5:1 against its ground in light and in dark, and a test fails if it does not.

Touch

The gear, close and add-step buttons are padded to 48 dp, the size Android asks for touch targets.

Motion

Animation runs about 180 ms and eases out. It stops when the phone asks for reduced motion.

Restore

Restore reads the whole backup file before it changes anything. A damaged file is refused with one sentence, and the sentence ends: Nothing changed.

Libraries

Three libraries. A new one needs a written decision first, and three unused ones were removed.

A decision, as written

Decision log, 29 October 2026. Excerpt.

Every decision is logged with the alternatives it beat and the condition that would reverse it.

Decision
Add palette.accentText, used only for text. Light is 886844; dark equals the dark accent. The brass stays for rules, icons, borders and cursors.
Reason
Light-mode brass text read 3.54:1 on white and 3.19:1 on the page ground. 886844 reads 5.11:1 and 4.60:1.
Alternatives considered

Darkening the brass everywhere: rejected; it changes every rule and icon to fix text.

856642 for the text token: 4.76:1 on the page ground, a heavier bronze; kept as the fallback.

Reverse when
A scanner reads any text use below 4.5:1 (set the light accentText to 856642).
